# 素材库重复图片隔离

本技能用于整库清理，不是单批选图。单批发帖选图用「image-asset-dedup-selection」。阈值以项目规则为准，下面的数字是参考值。网盘文件操作只在本人明确授权范围内进行，复用该网盘的官方 CLI 技能；默认只移动、不删除、不改名、不上传。本技能不是发布或删除授权。

## 1. 划定范围
- 列出目标素材库的完整目录（分页须拉完）。已发归档目录和已用台账里的原片只作对照基准，不移走。
- 视频是否纳入以当次授权为准；未授权则只处理图片。
- 已经存在的重复隔离目录不再当作待审源，只用于还原和对照。

## 2. 算哈希
- 每张图算 SHA256 和 64 位 pHash。HEIC 先 `pillow_heif.register_heif_opener()`，打开后先 `ImageOps.exif_transpose` 再算哈希。
- RAW（如 CR3）用内嵌预览图算感知哈希，并在汇报里说明这一局限。
- 文件大小相同，或改名后大小仍相同，不能当成同一张，必须以 SHA256 为准。
- 可复用已有本地哈希缓存，但要按文件名、大小、修改时间校验；对不上就重算。

## 3. 分组
- SHA256 相同为完全重复。
- pHash 汉明距离 ≤6（或项目规则给定的阈值）为近似候选，必须看联系表，不能只靠距离下结论。
- 原片与其导出图（如 RAW 与对应 JPG）不要互相当作重复；一边的保留或移走结论同步到成对的另一边。

## 4. 决定保留哪张
每组只留 1 张，其余计划移走。优先级：已发或台账原片 > 分辨率 > 文件大小（成对 RAW 按 RAW 大小）> 不带副本后缀（如 `(1)`）。
拿不准的（构图、表情、手势、人员位置有可见差别，或同一张图出现在两个活动目录、归属不清）留在原处，列入待人工确认，不移。

## 5. 联系表复核
为近似组生成带编号和距离的联系表，逐组看过再定。姿势或构图明显不同的，即使距离很小也保留，不当重复。

## 6. 移到可还原的隔离目录
- 在素材库下建立隔离目录（如「重复」）。按原相对路径建子目录，便于原样还原。
- 只移动已确认重复的文件；先写移动计划（保留项、移走项、原路径、哈希、距离），再按文件 ID 精确移动。
- 不删除、不改名、不覆盖已有文件。目标位置已有同名冲突则停下报告。

## 7. 移动后核对
- 重新列出全部相关目录。
- 计划移走的文件都在隔离目录对应子路径中，且原位置已经不在。
- 已发归档的清单与移动前完全一致；台账指向的原片无一被移动。
- 隔离目录里没有计划外文件。
- 保存计划、逐条核对结果和脱敏回执。

## 8. 使用约定
- 之后选图时，整份隔离目录都不要用；台账里把被移走的文件和对应保留件视为同一张。
- 汇报写明范围、移走数量、待人工确认的组，以及 pHash、预览图、未纳入视频等覆盖局限。不要写「库里已经完全没有重复」。

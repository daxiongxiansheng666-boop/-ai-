# 图片素材排重选图

阈值和比例要求以项目规则为准，下面的数字是参考值。

## 1. 建已用清单
- 汇总已发归档目录和已用台账里的文件名。
- 归一化：去掉 `(1)` 这类副本后缀、统一小写、去扩展名后比对。

## 2. 建历史哈希库
- 本地历史成图逐张算 SHA256 和 64 位 pHash。
- HEIC 先 `pillow_heif.register_heif_opener()`，打开后先 `ImageOps.exif_transpose` 再算哈希。
- 从平台近期发布记录下载封面一起入库。
- 限定范围（如最近 N 天或指定目录），不要无边界遍历全部历史，否则容易超时失控。哈希库可缓存复用，增量更新。

## 3. 筛候选
- 排除已用文件名、比例不符（如要求竖图）、原始像素不足的图。
- 素材库里已经隔离的重复目录（如「重复」）整夹排除，不再入选。
- 与历史库最近 pHash 汉明距离 ≤12 的剔除。

## 4. 本批互查
- 本批入选图两两距离保持 ≥14。
- 同一批（包括跨账号）不用文件名相邻的连拍（如编号相差很小的 IMG_xxxx），pHash 会漏掉这类近构图。

## 5. 联系表人工复核
- 生成带编号和最近距离的缩略联系表，逐张看一遍。
- 挑掉：手指挡镜、画面里有卖课感文字、同场景近构图、模糊失焦。

## 6. 留证据
- 写一个 JSON：每张入选图的文件 ID、SHA256、像素、与历史的最近 3 个距离及对应文件。
- 人工替换的图另记一份（换掉谁、为什么）。

## 结论边界
- pHash 不命中，不能证明没被裁切或加字后用过；视频只比了封面时覆盖不到中间帧。
- 汇报里写明查过的范围（哪些目录、哪几天的平台封面），不说「完全没重复」。
